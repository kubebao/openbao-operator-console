The OpenBao Operator Console is installed as {{ include "console.fullname" . }} in namespace {{ .Release.Namespace }}.

Check that it is ready:

  kubectl --namespace {{ .Release.Namespace }} rollout status deployment/{{ include "console.fullname" . }}

{{- if .Values.ingress.enabled }}

Open the console at:

  {{ $publicURL }}
{{- else }}

No Ingress was created. Route HTTPS traffic for {{ $publicURL }} to the {{ include "console.fullname" . }}
Service on port {{ .Values.service.port }} through your ingress controller or Gateway. For a local check of
/readyz only:

  kubectl --namespace {{ .Release.Namespace }} port-forward service/{{ include "console.fullname" . }} 8090:{{ .Values.service.port }}
  curl --fail http://127.0.0.1:8090/readyz
{{- end }}

Register this callback URL in your OpenID Connect client:

  {{ $publicURL }}/auth/callback

First administrator:
{{- if .Values.bootstrapAdminSubjects }}

  Automated bootstrap is configured. Sign in with an OIDC subject listed in bootstrapAdminSubjects.
  The runtime Secret must contain OIDC_ISSUER, OIDC_CLIENT_ID, and OIDC_CLIENT_SECRET.
{{- else }}

  On an empty database, the console opens browser setup at {{ $publicURL }}/setup. Unlock it with the
  {{ .Values.setup.tokenKey }} key from Secret {{ include "console.setupTokenSecret" . }}, then select
  "Verify with login" as the account that becomes the first administrator. The setup window lasts
  one hour from startup.

  After you have signed in as administrator, remove the token. No Helm upgrade is required:

    kubectl --namespace {{ .Release.Namespace }} patch secret {{ include "console.setupTokenSecret" . }} --type=json \
      --patch='[{"op":"remove","path":"/data/{{ .Values.setup.tokenKey }}"}]'

  An initialized database loads its stored configuration and ignores the setup token.
{{- end }}

Back up PostgreSQL and the CONFIG_KEY in Secret {{ .Values.existingSecret }}. A restored database cannot be read
without the matching key.

Documentation: https://github.com/kubebao/openbao-operator-console/tree/main/docs
